# Chess piece artwork

The twelve SVGs are the familiar Cburnett (Colin M. L. Burnett) Staunton-style
chess pieces. Source: https://github.com/lichess-org/lila/tree/master/public/piece/cburnett
(downloaded 2026-10-22). Originals and author attribution:
https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces
https://commons.wikimedia.org/wiki/File:Chess_plt45.svg
https://commons.wikimedia.org/wiki/User:Cburnett
